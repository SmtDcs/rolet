# public/art — Kilitli kareler (Sanat Yasası)

Sanat yasasına göre üretilen kareler buraya, şu isimlerle konur:

- `key-table.png` — anahtar görsel (önce bu kilitlenir; kilitlenmeden başka görsel üretilmez)
- `portrait-croupier.png` / `portrait-shooter.png` / `portrait-counter.png` / `portrait-dealer.png` — portreler
- `card-icons.png` — 12 ikonluk tek sayfa (4×3)
- `lobby-lock.png` — lobi kompozisyon kilidi

**Üretim kuralları:** düz kâğıt fon `#E6D7C3`, şeffaf PNG, filigran yok, çerçeve yok.
**Palet (yalnızca bunlar):** `#1A140F` mürekkep · `#E6D7C3` kâğıt · `#8C2F2F` kuru kan · `#C6A15B` pirinç · `#2F4A3C` is yeşili.
**Işık:** sol üstten tek kaynak; gölge sağ alta.
**Yasak:** mor neon, cam panel, gradyan, parlama, Inter, Space Grotesk, yeni renk, yeni yüz.

**Kabul:** palet dışına çıkan piksel varsa kare silinir · iki karakterin yüzü benzemiyorsa ikincisi yeniden üretilir · sayfada cam kart veya mor varsa çıktı alınmaz.
